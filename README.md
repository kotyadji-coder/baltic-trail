# Тропа · Калининградская область

Лёгкое веб‑приложение (PWA) для одной размеченной пешеходной тропы:

- 🗺️ карта (OpenStreetMap + топографический слой), трек тропы из **GPX** и **профиль высот**;
- 🧭 **навигация по тропе**: стрелка по ходу движения, «осталось / пройдено», ближайшая впереди точка, предупреждение с вибрацией при отклонении от тропы; если навигация была включена — после перезапуска приложения она сама возобновляется;
- 📍 точки интереса с категориями и примечаниями (добавляет/правит **только администратор**);
- 🛰️ показ своего местоположения по GPS; при открытии карта сама встаёт туда, где вы сейчас, и запоминает последний вид (центр, зум, выбранный слой карты, показаны ли точки/трек);
- ⬇️ **офлайн**: приложение устанавливается на домашний экран и работает без интернета; карту нужной области можно скачать заранее («Скачать карту этой области»);
- 🥾 **запись трека по GPS** (админ) — пройдите тропу с телефоном, приложение запишет трек и сохранит его в `.gpx`;
- 💾 экспорт точек в `GeoJSON` и импорт `GPX`/`GeoJSON` (админ).

Зелёная точка вверху справа — индикатор сети: зелёная = онлайн, красная = офлайн (карта берётся из скачанного кэша). Тапните по ней — покажет подсказку.

Стек: статика — Leaflet + ванильный JS + Service Worker. Сервер не нужен, кроме раздачи файлов.

## Как запустить локально

Service Worker и `fetch` к файлам данных требуют `http(s)` (не `file://`). Из папки проекта:

```bash
python3 -m http.server 8080
# затем открыть http://localhost:8080
```

или `npx serve` / любой статический сервер.

## Как опубликовать (бесплатно)

Это статический сайт — кладётся как есть на:

- **GitHub Pages**, **Netlify**, **Cloudflare Pages**, **Vercel** — просто залить папку.
- любой обычный хостинг/`nginx`.

Обязательно по **HTTPS** (нужно для геолокации и установки PWA). На localhost — тоже работает.

## Структура

```
index.html              — страница
css/style.css            — стили
js/app.js                — вся логика (карта, точки, GPS, запись, офлайн)
sw.js                    — service worker: кэш приложения + кэш тайлов карты
manifest.webmanifest     — манифест PWA
vendor/leaflet/          — Leaflet (лежит локально, чтобы работало офлайн)
icons/                   — иконки приложения
data/track.gpx           — трек тропы (замените на свой)
data/points.geojson      — точки «по умолчанию» (видны всем)
```

## Режим администратора (кто может править точки)

Обычные посетители видят только карту, трек и официальные точки — добавлять и редактировать ничего не могут. Чтобы войти как админ:

1. Откройте сайт с параметром `?edit=КОД`, например `https://ваш-адрес/?edit=1803`.
2. **Поменяйте код** в `js/app.js`: строка `const ADMIN_CODE = '1803';` — впишите свой секрет.
3. Режим запоминается в этом браузере (в меню есть «Выйти из режима администратора»). На телефоне-«рабочем» зашли один раз — и дальше можно без параметра.

⚠️ Это «защита через секрет в ссылке» — нормально для личной тропы (испортить общие данные всё равно нельзя, у каждого посетителя точки только локальные). Если нужен настоящий вход и общая база — это отдельный шаг с бэкендом (Supabase и т.п.).

## Как наполнять своей тропой (от имени админа)

1. **Трек.** Запишите его в приложении (меню → «Записать трек по GPS») или нарисуйте на <https://gpx.studio> и сохраните как `data/track.gpx`. Можно временно загрузить файл через меню → «Загрузить трек из файла».
2. **Точки.** На карте нажмите **＋**, коснитесь места, заполните название/категорию/примечание. Точки сохраняются в этом браузере (`localStorage`).
3. Когда точки готовы — меню → **«Сохранить точки (GeoJSON)»**: скачается `points.geojson`. Положите его в папку `data/` и перевыложите сайт — теперь эти точки видят все по умолчанию.
4. Бамп версии кэша: при обновлении файлов поднимите `APP_CACHE` в `sw.js` (например `...-v3` → `...-v4`), чтобы у людей подтянулась новая версия.

## Навигация по тропе (для всех)

Кнопка 🧭 на карте (или меню → «Вести по тропе»). Приложение привязывает ваше GPS-положение к линии трека и показывает: стрелку «куда идти» (относительно того, куда вы повёрнуты — по компасу телефона или по курсу GPS в движении), «осталось / пройдено», ближайшую впереди точку, а при отклонении дальше ~35 м — красный баннер и вибрацию. На iOS при включении навигации спросит доступ к компасу — без него стрелка работает только когда вы двигаетесь. Направление «вперёд» = так, как был записан GPX-трек. Если закрыть вкладку/приложение с включённой навигацией, при следующем открытии она возобновится сама (когда доступ к GPS уже разрешён); выключить — крестик на баннере навигации.

## Офлайн в лесу — как пользоваться

1. Дома/на вай‑фае откройте сайт, нажмите **«Установить»** (или «Добавить на экран «Домой»» в браузере).
2. Откройте район тропы на карте на нужном зуме → меню → **«Скачать карту этой области»** (качает текущий зум +3 уровня). Если область большая — приблизьте и скачайте по частям.
3. В лесу: запускаете с домашнего экрана, GPS работает, тайлы берутся из кэша. Индикатор сети справа вверху (зелёная точка) краснеет в офлайне — это нормально.

## Замечания

- Тайлы OSM/OpenTopoMap бесплатны, но у них есть [политика использования](https://operations.osmfoundation.org/policies/tiles/) — для личной тропы трафик копеечный. Для серьёзной нагрузки возьмите ключ MapTiler / Stadia / Thunderforest и замените URL тайлов в `js/app.js` и список хостов в `sw.js`.
- Сейчас точки хранятся в браузере и в файле `data/points.geojson`. Если со временем захотите, чтобы точки добавлялись с любого устройства и сразу синхронизировались — это +1 шаг: подключить Supabase (Postgres) и заменить чтение/запись `localStorage` на запросы к нему. Архитектура к этому готова (всё проходит через `loadUserPoints`/`saveUserPoints`).
- Демо‑данные (`data/track.gpx`, `data/points.geojson`) — это выдуманная петля около Рыбачьего на Куршской косе, просто чтобы было что показать. Замените своими.
